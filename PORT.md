# Codex port record

Upstream is Lauren Tan's pstack 0.15.48 from cursor/plugins commit `96af3b7a4eaf4bab2535d1591f29aae61a3c605d`. This local adaptation is version 0.15.48. Retain LICENSE and this provenance when redistributing.

The 59-skill main collection and all 23 playbooks are retained. Changes add a root entry skill and portable plugin manifest, normalize skill metadata, preserve existing invocation policies, and bind execution through skills/poteto-mode/references/codex-runtime.md. Model setup now uses project-local JSON with inheritance defaults. Delegation uses native tool schemas and explicit writer isolation. The plan checker and templates use installed-playbook and hourly-audit markers. History is scoped through available Codex tools. Worktree history is optional explicit input, and uncertain history cannot classify a checkout as safe to delete.

The PR watcher, decision logger, Bun lockfile, and their tests are retained. Upstream removed the orchestration CLI/store; the Codex coordinator uses native delegation and durable run files, retaining scheduler IDs, recovery, pinned leases, and one writer per branch. PR stacks follow actual dependencies. Runtime dependencies are not bundled. Provider-specific Benny and bot setup remains archived as labeled reference material; live entrypoints check actual connectors, triggers, credentials, and control evidence.

Creating this source folder does not install global skills, change Codex model settings, create automations, contact Slack, publish a PR, or enable a webhook. See VALIDATION.md for the checks actually run and their limits.

Source updates and every retained customization are tracked in [UPDATES.md](UPDATES.md), [UPSTREAM.json](UPSTREAM.json), and the linked per-file inventory. Follow [UPSTREAM.md](UPSTREAM.md) for future three-way updates.

Original source snapshots now live on `upstream`; `main` retains Codex adaptations. The two histories share a recorded baseline without rewriting published commits. See [AGENTS.md](AGENTS.md) for agent maintenance rules and [the history record](docs/upstream-history.md) for the initial bridge.


The statechart TypeScript pipeline introduced in 0.15.36 replaces the old `.mjs` tools and portable fault-injection harness. Its local fixes annotate the checker exit union, canonicalize the launcher fixture’s temporary path on macOS, and make two signal test callbacks return void. All other executable statechart files match upstream. The new suite exercises actual TLC checks, differential replay, CLI failures, signals, and SVG rendering. Rendering is separate from model checking; dependency installation remains scoped.

Since 0.15.42, `how` uses one read-only explanation delegate and `why` follows commits and PR discussions directly. Recall owns its source investigators; the old how/why prompt files are removed. Arena cross-judges require a known different vendor, with an explicit skip when none is configured or available. Upstream provider defaults, slug migrations, global rules, and relative per-role budget changes are not imported: Codex keeps supported model/effort objects, inheritance defaults, and existing user choices. The obsolete how-explorer and why roles are omitted from new setup examples but preserved in existing user configurations.

In 0.15.43, architecture sketches two shapes inline and uses Arena only for large or contested designs. Reflection reads scoped history inline and still requires approval before editing a source copy. The worker startup contract preserves user/repository checks, authorization and supported model settings. Babysit reports rebases to the branch owner; opening a PR no longer starts it automatically. The Codex port retains `orchestrate.md`, the full multi-phase plan contract, `check-plan.mjs`, its fixtures and seven Bun tests despite upstream deletions. There are 23 port playbooks versus 22 upstream. Retired reflection model roles stay untouched in existing user configurations; `architect runners` remains available for Arena.

In 0.15.46, statechart imports Windows newline handling, explicit UTF-8 Java output, and a TypeScript cleanup process using platform-specific process termination. The new executable files remain upstream-exact; the prior two-file macOS/type patch remains. Native Windows has not been exercised here. Upstream Gemini 4 Neon defaults, automatic panel migrations and provider-specific budget rules are intentionally not imported into active Codex instructions. Existing supported user model/effort choices remain authoritative.

In 0.15.48, `$reframe` adds source-checked terminology, neighboring-field comparisons and a rewritten description. Its explicit-only policy is expressed in `agents/openai.yaml`; the runtime binding preserves scoped source access and user constraints. Missing source access is reported, unconfirmed citations are omitted, and the underlying task is not implemented. All executable scripts remain identical to the validated 0.15.46 port.
